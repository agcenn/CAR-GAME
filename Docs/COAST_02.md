# Coast 02 使用说明

新版场景：`Assets/Scenes/Race_Coast_02.unity`。`Race_City_01` 是保留的旧版，不再作为默认打包场景。

## 打开和操作

本次 RVP 参考物理改造必须重新打包后再运行 `Builds/Windows/NeonHarbor.exe`；已有 exe 仍是改造前版本。详见 `Docs/RVP_REFERENCE.md`。
编辑时用 Unity Hub 打开项目根目录，使用 Unity 2022.3.62f1c1，双击新版场景并点击 Play。先单击 Game 画面以获得键盘焦点；Unity 顶部 Pause 按钮必须关闭。

W/S 或方向键：油门、刹车和倒车；A/D：转向；Space：漂移；左 Shift：槽满后氮气；L：车灯；Backspace：回到最近的赛道位置；Enter：重新比赛。冲线完成两圈后按 R 播放本局，再按 R 退出回放。

## 场景与画面

场景采用内置渲染管线的 Standard 材质，避免 URP 未配置引起的粉色材质。原创海港赛道包含连续道路网格、多个不同半径弯道、蓝白路肩和起跑线、安全墙、起点标牌、商铺楼体、棕榈树、看台与路灯。可编辑路径为 `Editable Racing Path`。

车辆包括独立滚动轮胎、轮毂、侧箱、尾翼、排气管、灯具和坐姿车手。车手的头盔、遮阳镜、四肢与手套均为代码构造的原创几何模型。属于风格化 3D 原型，不是照片级扫描模型。

材质：路面平滑度 0.12，车漆 0.72 / 金属度 0.32，玻璃 0.82 / 金属度 0.35。光照：线性色彩空间，太阳强度 1.15、旋转 (48,-32,0)、柔和阴影 0.65；天空/水平/地面三色环境光；4x MSAA；阴影距离 100m；线性雾 130–360m。无需外部后处理包。

## 比赛与回放

检查点按顺序通过后才允许计圈，AI 不会改变玩家圈数。排名累计跨越起点的路径进度。AI 按前方曲率降速，并探测前车减速/避让；不是保证绝不碰撞的规划系统。

单圈最佳、本局总时间写入 PlayerPrefs。回放在 `Application.persistentDataPath/Replays` 下保存 JSON，记录玩家、对手姿态及玩家仪表、输入、漂移和氮气状态。播放时暂停车辆物理，结束恢复赛后位置和组件状态。

## 重新生成与打包

1. Unity 菜单 `Neon Harbor > Build Coast 02 Scene` 重新生成新版场景。
2. `Neon Harbor > Build Windows Game` 生成 Windows 64 位可执行程序。
3. 分享整个 `Builds/Windows` 文件夹，不能只发 exe。

生成器会更新 `Assets/Art/Generated`、`Assets/Materials/Generated` 和新版场景；手动修改新版场景前建议另存。旧场景保留。

自动测试：从项目根目录启动 exe 并添加 `--race-smoke-test`，只在这个参数存在时自动驾驶；记录日志并生成 `Screenshots` 下的真实游戏画面。测试通过标识为 `RACE_TEST_PASSED`。

## Ushi 与扩展

目前工程按后续要求参考 RVP 改写车辆模块，运行车辆使用 `KartController` + `RaycastWheel` + `ArcadeDrivetrain`。没有导入 Ushi 源包；已有 `UshiCarPhysicsBridge` 仅是接口样例，不参与当前车辆运行。

多人：将 `RaceVehicleInput` 作为客户端输入数据，服务器管理倒计时、检查点和名次；车辆需要预测/校正，远端姿态插值。不要同步现有单机 PlayerPrefs 作为权威成绩。
道具赛：新增独立道具库存与拾取触发器，将减速/护盾/加速等效果应用为有限时长的车辆状态；让服务器验证命中，避免直接在 UI 中改变车辆状态。
